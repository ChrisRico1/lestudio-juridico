# Lestudio Juridico

Hola! Soy Christian, de Gestores Asociados. Te pego abajo el perfil completo de Google Business

de un negocio cliente. Quiero que me armes una landing de UNA sola página con el estilo estándar

de nuestros sitios.

REGLAS DE ORO

1. NO INVENTES INFORMACIÓN. Usá únicamente los datos reales del perfil que te paso:

   nombre, rubro, dirección, teléfono, WhatsApp, horarios, servicios, redes y reseñas.

   Si falta algo, preguntame o dejá el espacio listo para completar. Decorar sí, inventar no.

2. TENÉ SIEMPRE EN CUENTA EL RUBRO. Adaptá el tono, los servicios destacados y la estructura

   a lo que vende el negocio.

3. Colores de marca: si el perfil los muestra, usalos. Si no, armá una paleta acorde al rubro

   y decime cuál elegiste. Tema oscuro elegante, tokens de color en CSS (oklch).

4. Tipografía: Inter para el texto, Sora para los títulos.

5. TODO el texto del sitio en español rioplatense con voseo. Cero textos en inglés

   (ni la pantalla de error ni la de "página no encontrada").

6. CTA principal: WhatsApp, botón verde con link wa.me al número del cliente y un mensaje

   precargado ("Hola, quiero consultar por..."). Teléfono como CTA secundario.

7. Reseñas: incluí las reseñas de Google TEXTUALES, copiadas tal cual, con el nombre de

   quien las escribió. Si aparecen la valoración general y la cantidad de opiniones, usalas

   como badge en el héroe.

8. Estructura: encabezado fijo con logo + botón de WhatsApp → héroe con titular fuerte,

   valoración y horario → servicios (los del perfil, con íconos) → reseñas → contacto

   (dirección, teléfono, horarios, mapa de Google, redes si aparecen) → pie con © año actual.

9. Detalles: título y descripción SEO en español, datos de contacto consistentes con el

   perfil en todo el sitio, sin estadísticas del panel de Google (vistas, etc.).

DATOS DEL NEGOCIO — PEGAR ACÁ EL PERFIL DE GOOGLE BUSINESS:

Es para armar un preset para abogados, los colores tienen que ser serios, NO IGUALES A LOS DE GESTORES ASOCIADOS. La estructura debe ser pensada para abogados y todo lo relacionado con el profesional legal. Va a ser para armar una publicidad en redes en la que pueda ofrecer este servicio web pero luego cuando me pasen los detalles de su marca, etc.
